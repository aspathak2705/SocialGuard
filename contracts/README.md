# SocialGuard — Contracts

This directory contains formal specification contracts for data boundaries within SocialGuard.

- [account-contract.md](./account-contract.md): Specifications for target Instagram username and profile URL inputs, normalization rules, and validation responses.
- [collection-contract.md](./collection-contract.md): Specifications for planned multi-source data acquisition adapters (Instaloader, gallery-dl, Playwright), observation payloads, and future ML prediction contracts.
